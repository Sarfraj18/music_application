# 🎵 Flutter Music App UI

A beautiful and modern **Music Application UI** built using **Flutter & Dart**.  
This project includes only the **user interface**, with screens such as Home, Playlist, and Music Player.  
_No real audio playback is implemented — only UI elements are designed._

---

## ✨ Features (UI Only)

- 🎶 Clean and modern Music Player UI  
- ⏭️ Next, Previous, and Pause buttons (UI only)  
- 📃 Playlist page UI  
- 🏠 Home screen UI  
- 🎨 Minimal, attractive design  
- 📱 Fully responsive layout  
- ⚡ Built using Flutter and custom widgets  

---

## 🛠️ Tech Stack

- **Flutter**
- **Dart**
- **Material Design**
- **Custom Widgets**
- **Asset images/icons**

## 📌 Note
This project is a **UI-only Flutter Music Application**.  
It does **not** include real music playback features such as:
- Audio play/pause
- Background audio
- Music controls
- Notifications  
All buttons/icons (Play, Pause, Next, Previous) work only as **UI elements**.
